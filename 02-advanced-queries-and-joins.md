# Chapter 2: Relational Joins, Aggregations, and Subqueries

This section details advanced relational database querying methods. It covers individual syntax elements first, followed by multi-table architectures, grouping metrics, and subquery filtering.

---

## 1. Foundational Building Blocks (Isolated Concepts)

### The Standard Inner Join
Combines rows from two tables based on a shared, matching column.
*   **Definition:** Only returns records where the join key exists in **both** tables. Rows without matching keys are dropped.

```sql
SELECT 
    table_a.column_name, 
    table_b.column_name
FROM table_a
INNER JOIN table_b 
    ON table_a.shared_id = table_b.shared_id;
```

### The Standard Left Outer Join
Retrieves all records from the primary (left) table and any matching rows from the secondary (right) table.
*   **Definition:** If no match exists on the right, the query keeps the left row and displays `NULL` values for the right table's columns.

```sql
SELECT 
    table_a.column_name, 
    table_b.column_name
FROM table_a
LEFT JOIN table_b 
    ON table_a.shared_id = table_b.shared_id;
```

### Global Aggregation Function (Without Joins)
Calculates a single summary calculation across a targeted subset of rows in a single table.
*   **Definition:** Reduces an entire column of data down to a single value using mathematical expressions like `AVG()`, `SUM()`, `MIN()`, `MAX()`, or `COUNT()`.

```sql
SELECT AVG(numeric_column) AS summary_value
FROM table_name
WHERE filter_column = 'Target_Value';
```

### Basic Grouping (GROUP BY Without Joins)
Splits data into buckets based on a categorical column and calculates a summary metric for each bucket.
*   **Rule:** Every non-aggregated column in your `SELECT` clause **must** be listed inside the `GROUP BY` clause.

```sql
SELECT 
    category_column, 
    COUNT(primary_key_id) AS total_per_category
FROM table_name
GROUP BY category_column;
```

## 2. Relational Joins (Combining Data Tables)

### Multi-Table Inner Join with Grouped Counts
Combines multiple normalized tables to count the occurrences of a primary key across grouped dimensional categories.

```sql
SELECT 
    t1.dimension_name_1,
    t2.dimension_name_2,
    COUNT(jd.primary_key_id) AS total_records
FROM main_fact_table jd
INNER JOIN dimension_table_1 t1 ON jd.dimension_1_id = t1.id
INNER JOIN dimension_table_2 t2 ON jd.dimension_2_id = t2.id
GROUP BY 
    t1.dimension_name_1,
    t2.dimension_name_2
ORDER BY total_records DESC;
```

### Comprehensive Star-Schema Master Join
Joins an entire database schema together, converting abstract foreign key IDs into descriptive text fields for reporting or data exporting.

```sql
SELECT 
    f.fact_id,
    f.numeric_metric_1,
    d1.descriptive_text_1,
    d2.descriptive_text_2
FROM fact_table f
INNER JOIN dimension_table_1 d1 ON f.dim_1_id = d1.id
INNER JOIN dimension_table_2 d2 ON f.dim_2_id = d2.id;
```

## 3. Statistical Aggregations & Group Filters

### The HAVING Clause (Filtering Aggregates)
Filters grouped query results using computed statistical values.
*   **Crucial Distinction:** `WHERE` screens raw records *before* aggregation occurs; `HAVING` filters compiled group outputs *after* aggregation occurs.

```sql
SELECT 
    t1.dimension_name,
    AVG(jd.metric_column) AS average_alias
FROM main_table jd
INNER JOIN dimension_table_1 t1 ON jd.dimension_1_id = t1.id
GROUP BY t1.dimension_name
HAVING AVG(jd.metric_column) > 50
ORDER BY t1.dimension_name ASC;
```

## 4. String Manipulation & Subqueries

### Dynamic String Concatenation
Combines static descriptive text strings with active database columns to output custom formatted text reports.

```sql
SELECT CONCAT(column_text, ' static phrase text ', column_numeric, '% trailing syntax text.') AS formatted_sentence
FROM main_table m
INNER JOIN dimension_table d ON m.dim_id = d.id
WHERE m.condition_filter = 'High';
```

### Independent Scalar Subquery Filters
Filters a main dataset by matching row fields against the output values generated by a separate nested inner query.

```sql
SELECT * 
FROM table_name 
WHERE foreign_key_id IN (
    SELECT id 
    FROM lookup_table 
    WHERE status_condition = 'Target_Value'
);
```
